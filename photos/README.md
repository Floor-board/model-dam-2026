# Photos

## Purpose

Store project photos, visual progress documentation, and annotated build images.

## Recommended structure

```text
graphics/
├── construction/
├── final-build/
├── annotated/
└── measurements/
```

Use this folder for:

- build progress
- close-up detail shots
- final assembly photographs
- annotated images for design review
- before and after comparisons

---

Add clear captions or filenames so visual documentation remains interpretable later.
