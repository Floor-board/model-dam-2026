# Calculations

## Purpose

This section records the engineering calculations used to justify the dam design.

## Recommended structure

```text
calculations/
├── hydrology/
├── flow-rate/
├── README.md
└── assumptions-and-uncertainties.md
```

## Typical calculation topics

- inflow estimates
- reservoir storage volume
- spillway capacity
- outlet flow rate
- crest and freeboard checks
- seepage or drainage assumptions
- structural loads or stability estimates
- safety factors

## Calculation file practice

Each calculation file should include:

- objective
- equations used
- input values
- units
- assumptions
- final result
- references or source data

## Example headings

- Objective
- Inputs
- Equations
- Calculations
- Results
- Assumptions
- Notes

---

Add a calculation file for each major design question so the logic remains traceable.
