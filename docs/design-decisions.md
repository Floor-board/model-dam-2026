# Design Decisions

## Purpose

This document records the important choices behind the dam model design. Each decision should explain the reasoning, trade-offs, and any assumptions involved.

## Design overview

Describe the dam concept here:

- type of dam or model structure
- geometric form and layout
- principal components
- intended flow path
- expected operating mode

## Example decision categories

### 1. Dam geometry

- Why this shape?
- What trade-off is being made between capacity and strength?
- Does the geometry favour stability, discharge, or simplicity?

### 2. Spillway design

- What overflow pathway is used?
- Why is this spillway size appropriate?
- How does it handle extreme flow events?

### 3. Intake or outlet arrangement

- What is the flow-control mechanism?
- How is the system managed during normal operation and overflow?

### 4. Material selection

- Why were these materials chosen?
- What considerations apply to waterproofing, strength, or durability?

### 5. Electrical and control system

- Why were these components selected?
- What does the system monitor and control?
- What fail-safe logic is included?

## Design trade-offs

Capture any issues that required balancing competing needs, such as:

- increase in storage versus structural complexity
- spillway capacity versus cost and space
- automation versus simplicity
- measured precision versus project scope

## Revision history

Add dated entries for significant changes.

Example:

- [date]: Updated outlet geometry to reduce turbulence and improve flow stability.

## Open design questions

List unresolved issues or items to revisit.

Examples:

- confirm final reservoir depth
- validate material suitability for intended load
